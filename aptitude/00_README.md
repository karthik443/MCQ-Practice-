## How to use each file
1. Read the **Core formulas** and **Patterns** (10 min).
2. Cover the answers, attempt the **Practice MCQs** with a timer.
3. For every miss, re-read the pattern that applies and note it in the "Mistakes" box at the bottom.

## General MCQ tactics
- Eliminate options using units/magnitude before calculating.
- Use option back-substitution for "find the value" questions.
- Prefer fractions over decimals (1/8 = 12.5%, 1/6 = 16.67%, 1/7 ≈ 14.28%, 1/9 ≈ 11.11%).
- Skip anything taking > 2 min; come back if time remains (check if there's negative marking).
